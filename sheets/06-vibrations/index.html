Method

The masses sit in a line and move only sideways. Each spring and dashpot adds to the stiffness and damping matrices like a 1D truss element, so the equations of motion are

M ẍ + C ẋ + K x = F(t) free vibration: K φ = ω² M φ (generalized eigenproblem)

I solve the eigenproblem by Cholesky reduction (M = LLᵀ, then a symmetric problem for L⁻¹KL⁻ᵀ) and a cyclic Jacobi solver. The mode shapes come out mass normalized, φᵀMφ = 1. A free free chain has one mode at ω = 0, which is the whole chain sliding as a rigid body.

Damping: the dashpots and the optional Rayleigh term C = αM + βK build C. If ΦᵀCΦ is diagonal the damping is proportional and each mode gets ζ = (ΦᵀCΦ)ᵢᵢ / (2ωᵢ). If it is not diagonal the sheet says so, the ζ values shown are only the diagonal terms, and the frequency response is still exact because it solves the complex system directly:

(K − ω²M + iωC) X = F amplitude = |X|

The free response animation integrates the full equations with the Newmark average acceleration method, so it works for any damping. The mode animations are exaggerated and slowed down so you can see them.

Sound: real structures often vibrate at a few Hz, which you can't hear. So every frequency is multiplied by one shared factor that puts the lowest mode at 220 Hz. The ratios between modes stay exact, so the chord you hear has the same intervals as the structure. If that would push the top mode above 4 kHz, the spread is compressed on a log scale and the sheet says the intervals are no longer exact. With damping on, each tone decays faster when its ζ is larger (time constant 0.06/ζ seconds, kept between 0.08 and 1.2 s); this is a choice for listening, not a physical time scale.

Limits: linear springs and dashpots, small motion, one direction only.
